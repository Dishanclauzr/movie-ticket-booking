Normal Queue

FIFO Principle

First Come → First Served.
Order is based purely on arrival time. No customer can jump the line.

queue.shift() // removes from FRONT
VS
⚡

Priority Queue

Priority-Based

Highest Priority → First Served.
A VIP who arrives after a Regular customer still gets served first.

sort by priority, then serve queue[0]

🏷️ Priority Levels

Lower number = Higher priority
P1 🔴 VIP Served absolutely first. No exceptions.
P2 🟠 Senior Citizen Served after VIPs, before regular customers.
P3 🟡 Regular Standard ticket-holder. Served in arrival order among P3s.
P4 🟢 Normal Walk-in customer. Served last if higher priority customers exist.

⚡ Add to Priority Queue

* The queue auto-sorts by priority. A VIP added after a Regular will jump ahead automatically.

💻 Priority Queue Implementation

Sorted Array Approach 
// Priority Queue using sorted array
let pq = [];

// INSERT: Push then sort by priority number
function pqEnqueue(customer) {
  pq.push(customer);
  pq.sort((a, b) => a.priority - b.priority);
}

// SERVE: Remove highest priority (front)
function pqDequeue() {
  return pq.shift(); // front = lowest number
}

// PEEK: Inspect without removing
function pqPeek() {
  return pq[0];
}
